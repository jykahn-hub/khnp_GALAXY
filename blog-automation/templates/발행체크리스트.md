# 발행 체크리스트 (발행 전 마지막 관문)

> 이 체크리스트를 통과하지 못하면 발행하지 마세요.
> "완벽한 글"이 아니라 "저품질 판정 안 받고 + 전환되는 글"이 목표입니다.

## 1. 제목 & 노출
- [ ] 제목에 **핵심 키워드가 앞 15자** 안에 있다
- [ ] 제목 길이 **28자 내외** (모바일 안 잘림)
- [ ] 심리 트리거 1개 이상 (놀라움/공감/불안/욕망)
- [ ] 낚시 아님 — 본문이 제목을 지킨다

## 2. 도입부 & 체류
- [ ] 첫 3문장에 **훅** (인사말·워밍업 없음)
- [ ] 공감 → 정보 → 사례 → 정리 흐름이 있다
- [ ] 한 문단 2~3문장 / 한 문장 40자 내외
- [ ] 2~3문단마다 시각 요소(이미지·표·인용)
- [ ] 핵심 문장 볼드 처리

## 3. 신뢰 & 사실 (재테크·부업·앱테크 필수)
- [ ] **수치·날짜·금리·마감일 등 사실 검증 완료** ([확인 필요] 표시 다 해소)
- [ ] 후기라면 **실제 경험/스크린샷** 들어감 (조작 없음)
- [ ] 최신 정보인지 확인 (지원금·이벤트는 특히)

## 4. 수익 & 법적
- [ ] 제휴/추천 링크에 **"광고/제휴 포함" 고지** 있음
- [ ] CTA가 부드럽다 (저장→댓글→전환 순서)
- [ ] 링크는 신뢰 쌓인 **본문 후반부**에 배치

## 5. SEO & 기술
- [ ] 태그 5~10개 (핵심+연관 키워드)
- [ ] 대표 이미지 지정 (숫자·후킹 요소 보이는 것)
- [ ] 키워드 **과도 반복 없음** (스터핑=저품질)
- [ ] 이미지 대체텍스트/제목 활용
- [ ] 예약 발행 시간대 = 골든타임(07~09 / 12~13 / 21~23)

## 6. 최종
- [ ] AI 초안 그대로 아님 — **내 말투로 손질**됨
- [ ] 오탈자·어색한 문장 1회독 완료
- [ ] 이 글이 독자에게 **실제로 도움**이 되는가? (Yes여야 발행)
