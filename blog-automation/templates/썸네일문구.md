# 썸네일 문구 템플릿 (재테크·부업·앱테크)

> 썸네일은 "두 번째 제목"입니다. 제목과 다른 각도로 클릭을 한 번 더 잡으세요.
> 규칙: **큰 글자 12자 이내**, 숫자 강조, 대비 강한 색.

## 썸네일 문구 공식

```
[윗줄: 강한 후킹 키워드]  →  큼직하게
[아랫줄: 구체 숫자/결과]  →  포인트 색
```

## 유형별 문구 예시

### 후기형
- `앱테크 30일` / `진짜 얼마 벌었나`
- `한 달 실화` / `정산 공개`

### 손해회피형
- `모르면 손해` / `숨은 환급 4가지`
- `놓친 지원금` / `지금 신청`

### 리스트형
- `직장인 부업` / `TOP 5 비교`
- `초기비용 0원` / `부업 5개`

### 욕망형
- `출퇴근 30분` / `月 8만원`
- `커피값 공짜` / `앱테크 조합`

## 썸네일 제작 팁
- 배경: 정산 스크린샷/캡처 흐리게 깔면 신뢰감↑
- 숫자만 **다른 색**(빨강·노랑)으로 → 시선 고정
- 글자는 화면 1/3 이내, 나머지는 이미지
- 같은 시리즈는 **템플릿 통일**(브랜딩 + 연속 클릭 유도)

## 3안 뽑는 프롬프트 (복붙)
```
"[제목]" 블로그 글의 썸네일 문구를 3안 만들어줘.
각 안은 윗줄(후킹 키워드)+아랫줄(구체 숫자/결과), 각 12자 이내.
재테크·부업·앱테크 독자가 스크롤 멈추게, 서로 다른 각도로.
```
