# Step d. AI로 만드는 블로그 자동화 (매일 반복 워크플로우)

> 목표: 매일 [재테크·부업·앱테크]에서 검색량 오르는 주제를 찾고 →
> 제목·원고·썸네일 문구·발행 체크리스트까지 **자동으로 만드는 시스템**을 돌린다.

---

## 1. 전체 파이프라인 한눈에

```
┌─────────────────────────────────────────────────────────────┐
│  아침 15분: 수집 & 발굴          → Step a  (prompts/a)         │
│    · 실데이터 5분 수집(선택)                                   │
│    · AI로 고수요 각도 5개 → 오늘 1개 선정                       │
├─────────────────────────────────────────────────────────────┤
│  5분: 제목 & 도입부              → Step b  (prompts/b)         │
│    · 제목 5개 + 도입부 5개 생성 → 최적 1개 선택                 │
├─────────────────────────────────────────────────────────────┤
│  20분: 본문 초안 & 손질          → Step c  (prompts/c)         │
│    · 체류형 원고 생성 → 사람이 사실확인·경험 주입               │
├─────────────────────────────────────────────────────────────┤
│  10분: 썸네일 & 발행             → templates/                  │
│    · 썸네일 문구 3안 + 발행 체크리스트 통과 → 발행/예약         │
├─────────────────────────────────────────────────────────────┤
│  주 1회: 성과 리뷰 & 재활용      → 아래 6번                     │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 매일 실행 순서 (Daily SOP)

### ☀️ STEP 1 — 주제 발굴 (15분)
1. (선택) 네이버 VIEW 상위 10개 제목 복사 → 스프레드시트.
2. [`prompts/a_주제검증.txt`](prompts/a_주제검증.txt) 실행 → **각도 5개** 확보.
3. `01_주제_콘텐츠_검증.md`의 **점수표**로 오늘의 각도 1개 선정.
4. 나머지 4개는 "콘텐츠 큐"에 적재(내일 이후 재사용).

### ✍️ STEP 2 — 제목·도입부 (5분)
1. [`prompts/b_제목도입부.txt`](prompts/b_제목도입부.txt) 실행.
2. 제목 5개·도입부 5개 중 각 1개 선택 (심리 트리거 명확한 것).

### 📝 STEP 3 — 본문 (20분)
1. [`prompts/c_본문작성.txt`](prompts/c_본문작성.txt) 실행 → 초안.
2. **사람이 반드시 손질** (아래 3번 "AI 신뢰 규칙" 준수):
   - 실제 경험·수치·스크린샷 주입 (후기 각도면 필수)
   - 사실관계·최신정보 검증 (지원금 마감일 등)
   - 문장 톤을 내 말투로 다듬기

### 🖼️ STEP 4 — 썸네일 & 발행 (10분)
1. [`templates/썸네일문구.md`](templates/썸네일문구.md)로 썸네일 문구 3안 생성 → 1개 선택.
2. [`templates/발행체크리스트.md`](templates/발행체크리스트.md) 전 항목 통과 확인.
3. 발행 또는 예약 (발행 시간대는 아래 5번 참고).

> 위 4스텝을 한 번에 돌리는 통합 프롬프트: [`prompts/d_일일자동화.txt`](prompts/d_일일자동화.txt)

## 3. AI 자동화의 필수 안전장치 (이거 안 지키면 블로그 죽습니다)

| 원칙 | 이유 |
|------|------|
| **AI 초안 100% 그대로 발행 금지** | 네이버는 저품질 양산글을 걸러냄(저품질 블로그化 위험) |
| **사실·수치는 사람이 검증** | 지원금 마감일·금리 등 틀리면 신뢰·법적 리스크 |
| **경험/후기는 진짜만** | 조작 후기는 적발 시 치명적, 후기 각도의 생명은 진정성 |
| **제휴/광고 고지 필수** | 공정위 표시광고법 위반 방지 |
| **하루 1편, 꾸준함 > 양** | 갑자기 다량 발행은 어뷰징 신호로 인식될 수 있음 |
| **키워드 반복 남용 금지** | 과도한 키워드 스터핑은 저품질 판정 요인 |

> 자동화의 목표는 "사람을 없애는 것"이 아니라 **"사람의 반복 작업을 없애고 판단만 남기는 것"**입니다.

## 4. 발행 최적 타이밍 (재테크·부업·앱테크 독자 패턴)

- **오전 7~9시** (출근길, 앱테크·부업 정보 소비 피크)
- **점심 12~13시** (직장인 검색 급증)
- **저녁 21~23시** (하루 마무리·재테크 검색)
- 시즌 이슈(지원금·연말정산)는 **마감 7~10일 전** 선점 발행.

→ 예약 발행으로 위 시간대에 자동 게시. 하루 작업은 아침에 몰아서, 노출은 골든타임에.

---

## 5. 주간·월간 루틴 (성과 복리화)

### 주 1회 — 성과 리뷰 (일요일 저녁 20분)
1. 지난 7편의 **조회수·체류시간·저장·유입 키워드** 확인 (네이버 블로그 통계).
2. 분류:
   - 🔥 **터진 글** → 같은 각도로 시리즈화 / 상세편 제작 / 다른 각도로 재활용
   - 😐 **평타** → 제목만 교체해 A/B 재시도
   - ❌ **부진** → 왜 안 됐나 1줄 메모 (다음 주제 발굴 필터로)
3. "터진 각도"를 Step a 프롬프트에 참고 데이터로 다시 투입 → **선순환**.

### 월 1회 — 수익 & 방향 점검
- 애드포스트/제휴/추천 수익 집계 → 어떤 각도가 돈이 됐나.
- 전환 잘 되는 글의 CTA·제휴 배치를 다른 글에 이식.
- 검색 유입 상위 키워드로 다음 달 콘텐츠 계획 수립.

---

## 6. "더 자동화" 하고 싶다면 (고급, 선택)

| 도구 | 자동화 포인트 |
|------|-------------|
| **구글 스프레드시트 + AI** | 수집 데이터 정리 → 프롬프트 자동 조립 |
| **예약 발행** | 네이버 블로그 예약 기능으로 골든타임 자동 게시 |
| **키워드 알림** | 네이버 데이터랩 / 구글 트렌드로 급상승 키워드 모니터링 |
| **콘텐츠 캘린더** | 노션/스프레드시트에 큐·발행일·성과 트래킹 |
| **API 연동(코딩 가능 시)** | 네이버 검색광고 API로 검색량 자동 수집 → 스크립트화 |

> ⚠️ 완전 무인 자동 발행(AI가 사람 검수 없이 직행)은 **권장하지 않습니다.**
> 저품질 판정·법적 리스크·신뢰 붕괴의 지름길입니다. **"판단"만은 사람이 쥐세요.**
