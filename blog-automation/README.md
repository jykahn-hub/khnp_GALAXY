# 블로그 수익 자동화 시스템 (재테크·부업·앱테크)

> 매일 "검색량 오르는 주제 발굴 → 클릭되는 제목 → 체류형 원고 → 썸네일 문구 → 발행"까지
> 반복 가능한 워크플로우로 돌리는 개인용 블로그 자동화 운영 매뉴얼입니다.

---

## 이 시스템이 하는 일

이 폴더는 "완성된 글 하나"가 아니라 **매일 물고기를 잡는 자동 낚시 시스템**입니다.
아래 4단계를 매일 같은 순서로 돌리면, 사람이 감으로 하던 작업이 프롬프트 실행으로 바뀝니다.

| 단계 | 파일 | 핵심 산출물 |
|------|------|------------|
| **a. 주제 & 콘텐츠 검증** | [`01_주제_콘텐츠_검증.md`](01_주제_콘텐츠_검증.md) | 고수요 콘텐츠 각도 5개 |
| **b. 제목 + 체류 설계** | [`02_제목_체류_설계.md`](02_제목_체류_설계.md) | 제목 5개 + 도입부 5개 |
| **c. 글 구조 설계 (체류형)** | [`03_글구조_설계.md`](03_글구조_설계.md) | 완성된 본문 1편 |
| **d. AI 블로그 자동화** | [`04_자동화_워크플로우.md`](04_자동화_워크플로우.md) | 매일 반복 워크플로우 |

바로 복붙해서 쓰는 프롬프트는 [`prompts/`](prompts/) 폴더에, 발행 체크리스트·썸네일 문구·원고 골격은 [`templates/`](templates/) 폴더에, 완성 예시글은 [`examples/`](examples/) 폴더에 있습니다.

## ⚠️ 먼저 알아둘 것 (중요)

**"최근 30일 실제 상위 성과 콘텐츠 데이터"는 이 문서가 지어낼 수 없습니다.**
어떤 AI도 네이버·인스타·유튜브의 실시간 검증된 조회수/성과 수치에 직접 접근하지 못합니다.
가짜 순위 데이터로 콘텐츠를 만들면 오히려 트래픽이 죽습니다.

그래서 이 시스템은 **"실제 데이터를 내가 5분 만에 수집하는 방법"**과
**"그 데이터를 AI에 넣어 콘텐츠로 변환하는 프롬프트"**를 분리해 제공합니다.
→ 데이터 수집은 [`01_주제_콘텐츠_검증.md`](01_주제_콘텐츠_검증.md)의 "1. 실데이터 5분 수집법" 참고.

---

## 하루 운영 흐름 (요약)

```
[아침 15분]  주제 발굴 → 검증 → 각도 5개 (Step a)
     │
[제목 5분]   제목 5개 + 도입부 5개 생성 → 1개 선택 (Step b)
     │
[본문 20분]  체류형 원고 초안 생성 → 사람 손질 (Step c)
     │
[발행 10분]  썸네일 문구 + 발행 체크리스트 통과 → 예약/발행 (Step d)
     │
[주 1회]     성과 리뷰 → 터진 각도 재활용 (Step d 후반부)
```

총 소요 시간: **하루 약 50분 → 숙련되면 30분.**

## 수익 구조 (재테크·부업·앱테크 기준)

이 분야가 수익화에 유리한 이유와 붙일 수 있는 수익원:

| 수익원 | 설명 | 이 분야 적합도 |
|--------|------|--------------|
| **네이버 애드포스트** | 조회수 기반 광고 수익 | ★★★ |
| **제휴마케팅(쿠팡파트너스 등)** | 앱·상품 추천 링크 수수료 | ★★★★★ |
| **앱테크 추천인 코드** | 가입 리워드 앱 추천 리워드 | ★★★★★ |
| **금융 제휴(카드·증권 CPA)** | 카드 발급·계좌 개설당 단가 | ★★★★ |
| **정보성 전자책·강의** | 축적된 글을 묶어 상품화 | ★★★★ |

> 핵심: **정보로 신뢰를 쌓고(체류형 글) → 자연스러운 CTA로 전환**시키는 구조.
> 광고를 위한 글이 아니라, 도움이 되는 글 끝에 광고가 붙는 구조여야 오래 갑니다.
