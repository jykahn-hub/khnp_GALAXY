The 4 Steps

4단계 프롬프트 시스템

각 단계 프롬프트에는 [분야]가 재테크·부업·앱테크로 이미 채워져 있습니다. 버튼을 눌러 복사한 뒤 ChatGPT·Claude·제미나이에 그대로 붙여넣으세요.

a

주제 & 콘텐츠 검증

콘텐츠 전략가
▸ 산출물: 고수요 각도 5개
  • 반복 제목 패턴·키워드·정보구조 분석
  • 네이버·인스타·유튜브 교차 반응 포인트
  • 검색수요·경쟁·수익연결 기준 우선순위화
b

제목 + 체류 설계

상위노출 카피라이터
▸ 산출물: 제목 5 + 도입부 5
  • 놀라움·공감·불안·욕망 심리 트리거 기반
  • 인사말 없는 3초 훅 도입부 설계
  • 클릭률+체류 최강 조합 자동 추천
c

체류형 본문 작성

체류형 포스팅 작가
▸ 산출물: 완성 원고 1편
  • 훅 → 공감 → 정보 → 사례 → 정리 → CTA
  • 모바일 체류 최적화(짧은 문단·볼드·이모지)
  • 미검증 수치는 [확인 필요] 자동 표시
d

일일 통합 자동화

콘텐츠 운영 시스템
▸ 산출물: a~d 한 번에 실행
  • 주제→제목→본문→발행세트를 한 프롬프트로
  • 썸네일 문구 3안 + 태그 + 발행 점검
  • 사람이 검수할 포인트 목록까지 자동 정리
